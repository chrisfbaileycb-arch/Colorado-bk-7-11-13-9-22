# Contributing

Use a branch and pull request. Keep changes limited, add tests, and run:

```bash
bun install --frozen-lockfile
bun test
bun run typecheck
bun run build
```

Never submit real client data, credentials, generated client PDFs, signed forms, screenshots containing PII, or realistic identifiers. Use unmistakable synthetic placeholders.

Changes to statutes, exemptions, court rules, form mappings, means-test values, or filing workflows require authoritative citations, effective-date metadata, regression tests, and review by qualified bankruptcy counsel.
